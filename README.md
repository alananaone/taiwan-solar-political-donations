# 台灣太陽光電政治獻金交叉驗證資料集與計算程式（2018～2024 年 12 類公職選舉）

本專案公開台灣太陽光電產業於 **2018 年（107 年）、2020 年（109 年）、2022 年（111 年）與 2024 年（113 年）** 共兩屆 12 類公職選舉之政治獻金交叉比對程式（`scripts/`）與統計輸出明細（`output/`），供新聞查核、公民監督與研究社群複驗。

## 二、資料來源與驗證連結

本專案原始檔案皆取自以下法定公開或開放資料來源（`raw/` 目錄因原始壓縮檔超過 640 MB 未納入版本控制，請依下列來源自行取得後依序執行 `scripts/01_*.py` 至 `scripts/11_*.py`；公開前再執行 `scripts/12_prepare_public_outputs.py` 整理）：

1. **監察院政治獻金公開查閱平臺**：<https://ardata.cy.gov.tw/data/search/individual>（法源依據：《政治獻金法》第 21 條 <https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0020049&flno=21>）

4. **中央選舉委員會候選人政黨與當選名冊**：<https://github.com/kiang/db.cec.gov.tw>
5. **政府電子採購網開放資料 API（PCC）**：<https://pcc-api.openfun.app/api/getinfo>
6. **經濟部商工登記資料 API（g0v）**：<https://company.g0v.ronny.tw/>
7. **經濟部能源署太陽光電公開資料集**：<https://www.moeaea.gov.tw/ECW/populace/opendata/wHandOpenData_File.ashx?set_id=54>
8. **太陽光電七大公協會公開名錄**：PVGSA（<https://www.pvgsa.org.tw/company/list/>）、TPiSA（<https://www.tpisa.com.tw/%e7%90%86%e7%9b%a3%e4%ba%8b/>）、TPVIA（<https://www.tpvia.org.tw/index.php?do=member&act=list>）、TREA（<https://www.trearoc.org.tw/xmdoc?xsmsid=0O275351201511575794>）、SPEQSA（<https://www.speqsa.org.tw/index.php?option=com_zwin_combo&act=member>）

## 三、目錄與主要檔案說明

* `scripts/`：`01` 至 `12` 步驟完整 Python 資料清洗、雙源對帳、三級企業分類、中選會與 PCC 串聯、自然人四級防誤判比對及視覺化產生腳本。
* `output/`：
  * [台灣光電機構政治獻金交叉驗證分析報告.md](output/台灣光電機構政治獻金交叉驗證分析報告.md)：完整方法論與各項統計摘要報告。
  * [光電政治獻金_政黨與個人流向總覽.html](output/光電政治獻金_政黨與個人流向總覽.html)：互動式資料視覺化儀表板（瀏覽器可直接開啟）。
  * `09_two_term_party_comparison.csv`：2018／2020 年與 2022／2024 年各政黨企業捐贈彙總表。
  * `11_combined_corp_and_person_two_terms.csv`：企業與 L1 自然人合併彙總及 L2 隔離對照表。
  * `09_solar_companies_pcc_two_terms.csv`：191 家光電與供應鏈企業及 PCC 標案交叉明細。
  * `11_natural_person_L1_donations.csv`：L1 高信心自然人捐贈 118 筆（68 人），含捐贈人姓名、受贈候選人、金額、日期、比對到的公司與判定依據；不含證號、性別與地址。公司與捐贈人的連結為本專案比對推定，非監察院公開內容。
  * `11_natural_person_level_summary.csv`：L1／L2／L3／X 四級筆數與金額彙總。L2、L3、X 為疑似或同名者，不公開逐筆資料。
  * 為避免誤傷同名民眾，含 L2／L3／X 姓名的逐筆明細與名冊不納入本倉庫；研究者可依第二節來源與 `scripts/` 自行重現。
  * 本資料僅供公共監督與研究使用，請遵守監察院平臺使用須知，不得作為營利、徵信或其他不正當目的。若有誤認，請提出 Issue，查證後更正或移除。
  * `10_party_annual_solar_donations.csv`：107～114 年度政黨年度專戶光電關聯捐贈明細。
  * `10_group_penetration_donations.csv`：GCIS 集團關聯企業獨立追蹤明細。

## 四、資料邊界與計算誤差說明

1. **個人捐款之同名與遮罩限制**：監察院公開資料對自然人身分證字號後 7 碼與詳細門牌採取遮罩處理。本研究已剔除 1,531 筆同名衝突紀錄（L3），並將 81 筆缺乏交叉共現證據的疑似大額紀錄（L2）隔離不計入確定總額；因此確定數據屬於保守低估，但仍無法百分之百排除極少數「同姓同名、同性別、同出生縣市代碼且恰巧同投同一候選人」之巧合。
2. **企業歸類與多角化經營誤差**：部分供應鏈廠商或集團母子公司同時跨足鋼鐵、機電、營造或其他非光電業務，公開申報資料無法依單筆獻金拆算業務占比；反之，若業者以未具再生能源代碼之一般投資或控股公司捐贈，則不會計入核心光電企業總額。
3. **登記時點與政府標案範圍差異**：經濟部商工登記之董監事名單與公協會名錄反映資料擷取當下之狀態，部分公司負責人近年曾異動或辭任；政府電子採購網亦包含業者承攬之非光電工程或物資採購。
4. **後續更正與返還變動**：若候選人或政黨於本資料擷取時點後向監察院提出更正申報、返還或繳庫，實際數值仍應以監察院「政治獻金公開查閱平臺」最新公告為準。

如於程式邏輯或個別公司分類中發現疏漏，歡迎提出 Issue 或 Pull Request 指正。
